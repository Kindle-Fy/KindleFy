# 📖 KindleFy

![KindleFy Screenshot](https://via.placeholder.com/800x400?text=KindleFy+Screenshot)

## 📌 About The Project

**KindleFy** is a web application that mimics the interface and functionality of **Amazon Kindle**. The site provides an authentic Kindle reading experience directly in your browser – a book library, a reader with adjustable font size, and a clean, minimalist design.

The project is fully open-source and can be viewed, used, or extended freely.

🔗 **Live Demo:** [https://your-username.github.io/KindleFy/](https://your-username.github.io/KindleFy/)

---

## ✨ Features

- 📚 **Book Library** – visual display of all available titles
- 📖 **Integrated Reader** – open and read books in a clean web interface
- 🔤 **Font Size Control** – A+ and A- buttons to adjust text size
- 🌙 **Kindle Aesthetic** – minimalist design inspired by the original Kindle interface
- 📱 **Fully Responsive** – works on all devices (desktop, tablet, mobile)
- 🔄 **Fast & Lightweight** – built with pure HTML, CSS, and JavaScript

## 🚀 Getting Started Locally

### 1. Clone the repository

```bash
git clone https://github.com/your-username/KindleFy.git
cd KindleFy
```

### 2. Open in your browser

Simply open the **`index.html`** file in your favorite browser.

**Or** use Live Server (if you have VS Code):

```bash
# Install Live Server (if you don't have it)
npm install -g live-server

# Start it
live-server
```
