# 📚 KindleFy

KindleFy is a web app designed to bring useful tools and entertainment together in one place, with a clean interface inspired by Kindle.

## ✨ Features

- 📝 Notes
- 🧮 Calculator
- 🎮 Games
- ⚙️ Settings
- 📱 Installable as a PWA (Progressive Web App)
- 🌙 Clean and modern dark theme

## 🚀 Live Demo

https://kindle-fy.github.io/KindleFy/

## 📦 Technologies

- HTML5
- CSS3
- JavaScript
- SVG Icons
- Progressive Web App (PWA)
